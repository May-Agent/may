May - AI coding assistant

COMMANDS
  /help         Show this help
  /new          Create new session
  /session      Switch sessions
  /config       Provider settings
  /clear        Clear chat
  /secret K V   Store a secret in the OS keychain
  /quit         Exit

SHORTCUTS
  Enter         Send message
  ! command     Run a bash command in may's environment
  Ctrl+v        Paste image
  Ctrl+c        Quit
  Up/Down       History / Scroll chat
  Mouse wheel   Scroll chat
  g             Top
  G             Bottom
  Esc           Clear input

Type a message and press Enter to chat.
Type @ to attach files.
Prefix a message with ! to run it as a bash command; its
masked output is returned to the agent. Never type secrets
in bash mode — use /secret instead.
