Ask the user one or more questions without waiting for the answer. Returns a request_id at once; the answer arrives later as a message, possibly after this run has ended. Mark every task that depends on the answer BLOCKING <request_id> in tasks.md and keep working on the tasks it does not block; an unanswered question is no authorization, so never decide it yourself. Single question: ask_user "Which database?" --option PostgreSQL --option SQLite. Several questions: ask_user --questions '[{"section":"database","question":"Which DB?","option":["PostgreSQL","SQLite"]}]'.
