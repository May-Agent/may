# README outline

`README.md` has these sections, in this order, and no others at creation time:

1. `# <name>` followed by one sentence saying what the project is and who it is for.
2. `## Install`: the exact command(s) that install it (`cargo install <name>`, `bun add <name>`, a download link) or, for a project not yet released, the clone-and-build commands. Commands only, each in a code block.
3. `## Usage`: the smallest working example, as code the reader can paste, with the output it produces when the project prints something.
4. `## License`: one line naming the SPDX identifier chosen in step 1 and pointing to `LICENSE`.

No badges, no roadmap, no contribution section, no placeholder text such as "TODO" or "coming soon". Every command in the file was run or is the standard command of the toolchain, and the Usage example matches the code in the first commit.
