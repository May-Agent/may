`gh` is not available in the sandbox, and neither are its credentials. Issues reach GitHub through the `issue` command (`issue create`, `view`, `list`, `edit`, `comment`, `close`, `label`) and pull requests through the `pr` command (`pr open`, `list`, `show`, `merge`); run `issue --help` or `pr --help` for the rest. Only a command you run in unsafe mode, which the user approves, can use `gh`.
