Execute a terminal command. Each call starts a fresh shell; only a successful `cd` carries over. `interpreter` defaults to `shell`; `python` runs `script` as Python source, without a shell wrapper.

## Execution

- `timeout` is required and at most {{ timeout_cap_minutes }} minutes; the job and its process tree are killed when it passes.
- By default the call waits in the foreground for up to {{ foreground_secs }} seconds, then **promotes to a background job** under its `timeout` bound and returns its PID and output captured so far. Its completion is delivered automatically when it exits — carry on with other work or end your turn instead of polling with `{{ read }}` or attaching `monitor` just to wait for exit. Stop a background job with `kill <pid>`.
- Set `background: true` to detach immediately (for servers, watchers, or interactive programs). A foreground command reads end of file on stdin. Only a job started with `background: true` has a stdin: send it input with `{{ input }}`.

## Output Handling

- Command output strips control characters, collapses runs of blank lines, and converts JSON arrays of objects into TSV when smaller. Targeted file reads and searches stay verbatim.
- Oversized output is saved under `outputs/` (read the slice you need by absolute path with `rg`, `head` and `tail`, `sed -n`, or pipe through `ask`), returning a syntax-folded outline for whole-file or command source code and a head+tail preview otherwise.
- Set `raw: true` for verbatim stdout bytes without compression or folding (for checksums, binary protocols, or diffing).
